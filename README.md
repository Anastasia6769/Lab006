## «ПР6. Ответы на контрольные вопросы».
# 1. Чем void-метод отличается от метода, объявленного с типом возврата (например, int)?
void — это метод, который выполняет какие-либо действия, но ничего не возвращает. А метод с типом int возвращает целое число с помощью return.
# 2. Что происходит с выполнением метода в момент срабатывания return?
Когда срабатывает return, метод завершает свою работу и возвращает результат туда, откуда его вызвали.
# 3. Что такое перегрузка методов и по каким признакам компилятор выбирает нужную перегрузку при вызове?
Перегрузка методов — это когда несколько методов имеют одинаковое название, но разные параметры. Компилятор выбирает нужный метод по количеству, типу и порядку параметров.
# 4. Можно ли перегрузить метод, если у двух версий совпадают все параметры, а различается только тип возвращаемого значения? Почему?
Нет, нельзя, потому что компилятор не сможет отличить эти методы. Для перегрузки должны отличаться параметры, а не только тип возвращаемого значения.
# 5. Приведите свой пример (не из этой работы), когда логично разбить один большой кусок кода на два отдельных метода.
Например, в программе для подсчёта стоимости покупок можно создать один метод для расчёта общей суммы, а второй для вывода результата на экран. Так программа будет более понятной и удобной.
# 6. Что означает, когда один метод вызывает внутри себя другой метод? Как это связано с идеей переиспользования кода?
Это значит, что один метод использует другой для выполнения определённой задачи. Благодаря этому не нужно каждый раз писать одинаковый код заново, можно просто вызвать уже готовый метод.
